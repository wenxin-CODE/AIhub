**改写**

**踩坑与修复（重要，全部有回归测试）**
1. **Lee 滤波退化为恒等映射**：原实现用全图局部方差估噪声方差 → 权重恒为 1 → CV 只降 0.0%。改为从**暗区（局部均值最低 25%）**估计 σ_u²（乘性噪声，方差随信号强度变化）。修复后 CV 降 25.3%，均值偏移仅 0.61%。
2. **条纹方向判断反了**：水平条纹（`img[40:42,:]=220`）能量落在 **fx=0 列**（col_profile），不是行频谱。原判断写反导致水平→90°。已用 4 个用例（水平/垂直/均匀/随机噪声）锁定。
3. **条纹强度指标被自然纹理稀释**：原用"峰值/总能量"，真实含条纹影像只得到 0.0035。改用**峰值突出度** (peak−median)/peak，实测 0.44，正常且不误报。
4. **零强度与不可判定混同**：均匀图 FFT 能量全在 DC，去 DC 后 total=0，原返回 None。改为返回 0.0（确实无条纹），异常才返回 None。
5. **settings 无 image_dir 字段** → 启动即崩（`AttributeError`）。补 `Settings.image_dir` 并在 `ensure_dirs` 建目录。
6. **端口 8000 被旧进程占用** → 新代码没起来，表现为 404。用 netstat + taskkill 清理。

**新增设计决策**
- **算法层与图像库解耦**：指标计算不被重依赖卡住，且 L1/L2 天然共用同一套指标口径（横评可信的前提）。
- **管线由实测选出，不由 LLM 指定**：候选逐条实跑，统一指标横评择优。
- **5% 辐射强度守门**：中值滤波对乘性斑点系统性下偏（gamma(2,0.5) 中位数≈均值 69%），实测均值掉 12.8% → 被淘汰并记原因。降噪不能以破坏辐射强度为代价。
- **被拒管线必须带原因**：`rejected_pipelines` 落到 state 并推前端，"为什么没选它"必须可解释。

**验证数据（真实模拟 SAR 影像 512×512，含斑点 + 水平条纹）**
- 诊断：斑点 severe（CV=0.755，ENL=2.21）+ 检出水平条纹（突出度 0.445）

## 业务问题面梳理（用于方案/面试弹药）

用户问"这个项目针对的业务当前面临哪些问题"，做了行业检索，结论：StarOps 打的靶子是遥感行业公认的两大卡点——**观测规划靠人工排班**、**SAR 结论没人敢直接用**；AI 落地的真瓶颈不是模型精度，而是**可信度/可解释/可交付**。

**三级分层**
- 🔴 一级（项目正靶心）：① 观测规划靠人工排班、跨星座资源冲突（商业卫星无标准化接口；数传窗口重叠 68%、应急回传超时 41.3% —— **二手引用自 CSDN 问答引《高分星座运行白皮书》，引用前须核实原始出处**）；② SAR 降噪与辐射保真两难（Lee 边缘过平滑、Frost/Gamma-MAP 扩散点目标能量破坏后向散射定量反演、双线性/三次插值禁用于定量分析）；③ AI 结论不敢直接交付（小图斑/语义模糊边界/云影干扰/样本未覆盖四类须人工兜底；"准确率 90%"不带口径无参考价值）
- 🟠 二级：时效链条割裂（T&C 模式上注延迟即错过时窗）、数据源碎片化与多模态壁垒、预处理门槛（无正射校正会与矢量图错位）、样本与机理双重天花板
- 🟡 三级：成本（光学星座回报 4–6 年 / 雷达 6–8 年）、复合型人才短缺、商业化模式不成熟（卖数据→卖服务/卖决策）

**反向暴露的本项目缺口**：L2 深度模型未接入（T13/T14）、多轮改约束未实现（T06）、checkpoint 恢复未实现（T12）、SAR 数据源仍是合成影像未走通 SLC/GeoTIFF 定标链路（σ⁰/γ⁰ 入射角归一化未接）、约束规则集是手写确定性规则（未接侧摆角/续航/能量光照/Ka 频段数传优先级）。

## L2 深度模型接入：技术路径已摸清（未落地）

用户取消整仓 clone（62MB sample.tif 太重），改为只取权重文件。已下载源码到 `sar_ref/`（model.py / util.py / predictor.py / filter.py / tif2intensity.py），结论：

- 架构 = **red30 U-Net**（输入 256×256×2，4 次下采样 + 跳跃连接，无 BN、无 PReLU → **纯 numpy 可前向推理，无需 TF/PyTorch**）
- 权重 `resources/lin.hdf5` / `log.hdf5`（各 5.7MB，Keras HDF5）；解析需 **h5py**（小 wheel，避开 TF/PyTorch 数百 MB 下载）
- 推理链路：normalize → 分块 256 patch（stride 可配）+ 中心加权 mask → 累加平均 → mean_correction(smart/always/never) → denormalize
- 通道坑已确认：模型吃 **2 通道（VH+VV）**，单通道演示影像需显式复制为双通道再取回单通道
- 前向实现要点：conv 3×3 same + relu + maxpool2×2 + upsample nearest + concat

待办：装 h5py → 下载 lin.hdf5 → 写 `convert_weights.py`（h5→npz）+ `inference.py`（纯 numpy 前向）→ 接 `apply_dl_despeckle` → 接入 L1/L2 横评并覆盖 T13/T14。
